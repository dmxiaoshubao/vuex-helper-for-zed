# Vuex Helper for Zed Extension

This directory contains the Zed extension shell for Vuex Helper for Zed.

The extension starts the Vuex Helper language server and provides Vuex-related editor features in Zed.

## Features

- Go to Definition
- Code Completion
- Hover Information
- Diagnostics

## Requirements

- Zed editor.
- A Vue 2 project using Vuex 2.

## Current Scope

This extension focuses on Vuex State, Getters, Mutations, and Actions support through the language server.

## Not Included Yet

- Rename
- References
- Workspace Symbol
- Code Action
- Zed-specific configuration UI
